# Assets

This folder contains app assets like icons and splash screens.

## Required Assets

For Expo, you need to add the following files:

- `icon.png` - App icon (1024x1024px)
- `splash.png` - Splash screen (1284x2778px recommended)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `favicon.png` - Web favicon (48x48px or larger)

## How to Add Assets

1. Create your icon and splash screen images
2. Place them in this directory with the correct filenames
3. Run `npx expo start` to see them in action

## Using Default Expo Assets

If you don't add custom assets, Expo will use default placeholder images during development.

For production builds, you must provide your own assets.

## Tools
